# Controladores (Adapters / Controllers)

Esta camada contém os adaptadores de entrada (Driving Adapters).

## Conteúdo
- HTTP Controllers (ex: `LoginController`, `CreateContractController`).
- Responsáveis por receber a requisição (ex: HTTP Request), validar formatos de entrada rápidos e chamar o Caso de Uso apropriado, retornando a resposta formatada (ex: HTTP Response).
