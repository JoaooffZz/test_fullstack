# Provedores de Serviços (Infrastructure / Providers)

Esta camada contém as integrações reais com serviços externos e bibliotecas utilitárias de terceiros.

## Conteúdo
- Implementações concretas de serviços externos (ex: `NodemailerEmailProvider` implementando `EmailService`).
- Utilitários de criptografia, geração de tokens, etc.
